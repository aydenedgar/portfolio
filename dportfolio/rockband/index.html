Rockband Project

Lighting Designer and Programming


Rig Designed by Henry Ledbetter

and Dale Kaiser


As the final project for the Lighting I course at Colorado State University, I designed and programmed concert lighting for a song of my choice.

This project was programmed on an ETC Ion Classic in version 2.9.3, track on, auto-mark off. The programing is clean of Live and Dark move flags as well as broken marks.

The programming was pre-visualized through a link to Vision, that was modeled and configured by Henry Ledbetter and Dale Kaiser.
